# Dados

- `raw/`: fontes originais, nunca editadas à mão.
- `processed/matriz_maturidade_v0.csv`: matriz 5 empresas x 5 anos x 6 DAs (valores de 0 a 1).

Colunas: `empresa`, `ano`, `padrao_relatorio`, `DA_I` a `DA_VI`, `observacoes`.

Entrevistas (transcrições e gravações) ficam fora do repositório (`data/interviews/` está no `.gitignore`).
